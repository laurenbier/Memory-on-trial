# Memory on Trial

A PSYC 402 browser-based educational prototype exploring post-event misinformation, eyewitness recall, confidence, and a brief source-check correction.

## Run
Open `index.html` in a browser. No build tools, server, or external dependencies are needed. Publish these files at the root of a GitHub Pages repository.

## Design
Random assignment to accurate-report control, misleading-report, or misleading-report plus correction. All participants see the same fictional original event, 30-second distractor, and six forced-choice memory questions with confidence ratings. Three questions target details manipulated in the post-event report. The correction warns that three reported details may be inaccurate but does not reveal the true answers.

## Data and ethics
This **prototype does not send data to a server**. The participant can download a session-level CSV containing one row per memory question. No names or emails are requested. Before formal research-credit collection, obtain instructor approval, use the class-approved DataPipe workflow, and review consent language and research procedures. Never commit participant datasets or private credentials to the public repository.

## Planned evaluation
Primary: proportion of three misleading details endorsed by condition. Secondary: total correct answers and confidence calibration. The control group's misleading-detail endorsement score is defined using the same three false response options. The correction effect can be assessed by comparing misleading-report and correction groups. Random assignment should be checked and adequate sample size determined with the instructor.

## Important limitations
This short activity does not experimentally vary the delay between event and recall and cannot establish effects of long retention intervals. Text stimuli are not equivalent to real eyewitness perception. The source-check warning and test items need pilot testing. Results from one session are not evidence of an intervention effect.
